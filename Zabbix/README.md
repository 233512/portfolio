Zabbix - мониторинг Linux-инфраструктуры и сетевого оборудования

Учебный проект

Лабораторная работа 1: Развёртывание стенда на 3 ВМ (Debian): сети, SSH по ключам, установка Zabbix-сервера и агентов, интеграция с Grafana

Лабораторная работа 2: Централизованный сбор логов через syslog-ng с TLS: анализ ошибок в Zabbix и передача логов в Splunk (Docker)

Лабораторная работа 3: Кастомные плагины и внешние проверки: размер логов из Docker-контейнера через UserParameter, check_curl для веб-сервера, графики

Лабораторная работа 4: Уведомления в Telegram и автовосстановление: триггеры, бот через BotFather, скрипт авторестарта Apache2 с логированием

Лабораторная работа 5: Мониторинг маршрутизатора vSER (Eltex) по SNMPv3: элементы данных по OID, триггеры на трафик, статус порта и uptime

Лабораторная работа 7: Кастомный шаблон мониторинга Apache (server-status + макросы) и продвинутые дашборды Grafana с переменными и тегами

Лабораторная работа 8: Комбинированные триггеры «ошибки HTTP 500 + высокий трафик»: bash-скрипт подсчёта ошибок в логах, симуляция сбоев, итоговый дашборд

Лабораторная работа 10: Автоматизированное тестирование стенда: скрипт через Zabbix API симулирует сбои (CPU-нагрузка stress, остановка Apache, тестовые ошибки в логах) и проверяет срабатывание триггеров с отчётом
