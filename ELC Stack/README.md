ELK Stack — сбор и анализ логов

Учебный проект

Разворачивал инфраструктуру сбора и обработки логов на нескольких виртуальных машинах.

Настраивал Filebeat для сбора и передачи логов в Logstash.

Работал с Logstash и Elasticsearch для обработки и хранения данных.

Использовал Kibana для просмотра и анализа логов.

Диагностировал проблемы конфигурации и работы Elasticsearch-кластера.


Инструменты: Elasticsearch, Logstash, Kibana, Filebeat, Linux, VirtualBox
